# DYED – E‑Commerce Web Prototype

**Discovery Youth Employment Division** · Front‑end demo for POE submission.

---

## 1. Project Overview

A fully functional, single‑page HTML prototype for DYED’s programme catalogue and application flow. Built to demonstrate interface design, UX, and core e‑commerce interactions.

---

## 2. Features

| Feature | Description |
|---------|-------------|
| **Product catalogue** | 4 certified programmes with AI‑generated image placeholders |
| **Shopping cart** | Add/remove items, quantity updates, live total |
| **Checkout modal** | User details, qualification selection, file upload (mock) |
| **Responsive** | Mobile‑first, works on all screen sizes |
| **Interactive UI** | Sticky header, hover states, smooth animations |

---

## 3. Tech Stack

- HTML5 + CSS3 (vanilla, custom properties)
- JavaScript (ES6, no frameworks)
- Font Awesome 6 (icons)
- Google Fonts (Poppins)

---

## 4. Getting Started

### Run locally

1. Save `index.html` to your machine.
2. Double‑click to open in any modern browser.

**Optional (VS Code):** Install the "Live Server" extension, right‑click → *Open with Live Server*.

---

## 5. File Structure

```
/
└── index.html   # All code (HTML, CSS, JS) in one file
```

---

## 6. Limitations (Front‑End Only)

- No server‑side processing – cart and checkout are client‑side simulations.
- No real payment gateway – payment options are described only.
- File uploads are visual only (no backend).
- Data is stored in memory (resets on page refresh).
